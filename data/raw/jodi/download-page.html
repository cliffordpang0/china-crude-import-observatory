Data Downloads

Complete data series for all products, flows and countries, from January 2002 to one month-old can be downloaded, for free, in .ivt (Beyond 20/20), .csv and formats.

Full Dataset

  • Extended ivt
  • Monthly data availability by country (Excel format)

The last column in the csv files displays the colour codes: 1 for blue, 2 for yellow and 3 for white
Extended ivt is available with data starting from January 2009. To read .ivt file you need to install the Beyond 20/20 Browser.

Annual Datasets

Data is available in annual csv files. The latest annual file contains the year to date data.

JODI REST API

JODI-Oil data is also available programmatically through the JODI REST API, providing an alternative way to access data and integrate into your own systems.

To use the API you will need a JODI website account. If you do not already have one, you can register for a free account.

For details of the available endpoints, authentication, data queries, response formats and code examples, please download the JODI REST API Manual.
